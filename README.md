# React starter

A Create React App starter made on CodeSandbox. The npm package is named `react`, and the description in `package.json` is "React example starter project". Application code is `src/App.js` and `src/index.js`.

## Run locally

```bash
npm install
npm start
```

Open [http://localhost:3000](http://localhost:3000). `npm run build` writes the production bundle to `build/`.
